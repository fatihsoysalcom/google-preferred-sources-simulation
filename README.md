# Google Preferred Sources Simulation

This Python script simulates how Google might prioritize search results from 'preferred sources'. It assigns a higher ranking boost to sources marked as preferred, demonstrating the concept of preferential treatment in search.

## Language

`python`

## How to Run

Run the script using: python preferred_sources.py
